01

今の仕事を辞める時期の決め方

わしの助言だ。決まりではない。入社日がメールで伝えられてから、今の会社に言え。決まる前に辞めると、間が空いたときに困るのはあんただ。

公式に書いてあること

  • 合否は、面接のあと通常4日〜1週間でメールが来る。合格した人には、そのあと「入社日」が伝えられる。
  • 入社日は、基本的に2週間〜1ヵ月先が示される。面接のときに希望の入社日を聞かれる。
  • 生産の状況によっては、2〜3ヵ月先の入社日を案内されることもある（よくある質問）。
  • 今の仕事の退職時期に合わせた入社時期の調整も、相談できる（よくある質問）。
  • 入寮の準備は入社の1週間前から。1日目（月曜）に仮の寮へ集合する（くわしくは06）。

入社日から逆算する

  1. 集合日1日目（月曜）、仮の寮に集合。この日には、もう寮にいる。
  2. その前移動の日。遠いなら前日に動く。移動にかかる時間は、あんたの住む所で決まる。
  3. さらに前今の会社の最後の出勤日。荷造り・部屋の明け渡し・役所や郵便の手続きの日を、最後の出勤日と集合日のあいだに取っておけ（02を見ろ）。
  4. いちばん前今の会社に辞めると伝える日。今の会社の決まり（就業規則）に「何日前までに言う」と書いてある。最後の出勤日から、その日数を引く。

引いた日が、もう過ぎていたら。入社日をずらす相談ができると公式に書いてある。無理に詰めるな。

法律の話は一般論だけ書いておく。期間の決まっていない雇われ方なら、申し出てから2週間で辞められると一般に言われる。ただ、契約の形や会社の決まりで話が変わることがある。わしは断定しない。迷ったら、今の会社の決まりを読んで、それでもわからなければ労働の相談窓口に聞け。

もう一つ。今の会社の最後の給料がいつ入るかも、確かめておけ。トヨタの最初の給料は、入社した翌月の25日だ（03で計算する）。

06

入寮5日間の流れ表

月曜に集まって、金曜に自分の寮へ移る。公式の流れをそのまま並べた。

  1. 1日目（月）集合・仮の寮に入る自分の家から交通機関で、仮の寮「第2聖心清風西寮」へ。名鉄「土橋駅」から無料のシャトルバスがある。
  2. 2日目（火）健康診断・入社の手続き朝8時からバスで移動して健康診断。そのあと入社の説明と書類づくり。17時ごろ終わって寮へ戻る。
  3. 3日目（水）適性検査関節や指の動きの確認、握力、手先の器用さ。
  4. 4日目（木）安全教育・配属先の工場が決まる1日座学。社員証と健康保険証が渡される。最後の時間に「配属先工場」が知らされる。
  5. 5日目（金）自分の寮へ移る午前中に仮の寮を出る。「配属部署」が決まり、仕事の説明と制服の支給。バスで勤務地へ移って、指定の寮に入る。
  6. その翌日正式に勤務が始まる公式の書き方のまま。工場に配属された初日は、入社オリエンテーションのあと勤務開始。

公式には「採用状況や時期により若干採用の流れが変更になることもある」と書いてある。実際の日程は合格者への案内で確認しろ。どの工場・どの寮になるかは、4日目まで決まらない。

手当が出なくなる欠勤日数メモ

ここが一番大事だ。休んだ日数で、もらえる額が大きく変わる。スマホに写しておけ。

手当出なくなる条件（公式）
入社時特別手当 40万円入社日から入社した翌月の末までに、欠勤が5日以上あると対象外。入社した翌月の末に在籍していることも条件。
6ヵ月満了特別手当 60万円入社日から6ヵ月満了日までに、欠勤が8日以上あると対象外。6ヵ月（2回目の契約）を満了した人だけ。
満了慰労金満了した人に、出勤した日数分。欠勤・遅刻・早退・休職・特休0%の取得日・休日出勤日は、その日の分が出ない。
満了報奨金欠勤・遅刻・早退・休職のない月だけ、1日1,500円×その月の出勤日数。1回でも休むと、その月の分がまるごと出ない。特休0%の取得日・休日出勤日も対象外。
  • 40万と60万は、2026年9月以降に入社した人が対象。期間は変更になる場合がある（公式）。
  • 満了慰労金と満了報奨金は別物で、条件も違う。2つを合わせて「満了金」と呼ぶ。途中で辞めると、どちらも出ない。
  • 有給休暇は、入社から6ヵ月たってから10日付く（公式）。最初の半年は有給がない前提で考えろ。
  • 計算の例：出勤20日の月なら、報奨金は1,500円×20日＝3万円。その月に1回遅刻すると、この3万円が出ない。
公式に書いていない：遅刻や早退を「欠勤」の日数に数えるか。体調を崩して休んだ日の扱い。合格者への案内か、職場で確認しろ。

公式の表のまま。6〜30ヵ月は稼働122日、35ヵ月目は120日の場合で、入社日で変わる。6ヵ月まで続けた場合、3ヵ月の区切りでは支給されず、6ヵ月のあとにまとめて出る。13の例（5/13入社）の12月分は、満了慰労金215,900円＋満了報奨金190,500円＝406,400円で、この表（稼働122日の場合）と額が違う。稼働日数は入社日で変わる（公式）。どの区切りも、途中で辞めると出ない。

3つの道

  • 更新する：会社が「生産の見通し・業務量」と「本人の勤務成績・態度・能力・健康・体力」を考えて、必要と判断したときだけ更新される（公式）。希望すれば必ず、ではない。
  • 区切りで満了して辞める：その区切りの満了金が出る。帰りの旅費（帰任旅費）は満了した人だけ。
  • 区切りの途中で辞める：満了金は出ない。帰任旅費も出ない。

6ヵ月をこえて続けると：有給休暇が10日付く（入社から6ヵ月後）。家族手当は、6ヵ月以降に更新した人で、18歳未満の子1人につき月25,000円。

公式に書いていない：満了したあと寮にいられる日数、寮を出るときにかかる費用。職場か寮の管理室で確認しろ。

  • 勤務期間1年以上
  • 職場の上長の推薦
